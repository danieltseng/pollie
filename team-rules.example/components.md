# Using components

- If the design system has the component, use an instance — never rebuild it from frames.
- If only a similar component exists, prefer it and adjust its variants/properties; build your own only when it really doesn't fit.
- When you build something yourself, still use DS parts inside it (buttons, icons, dividers) and bind colors, text styles and spacing to tokens/styles.
- Never detach an instance to restyle it, and don't force a component into a role it isn't meant for.
- Mention in your reply anything you built by hand because the DS had no match.
